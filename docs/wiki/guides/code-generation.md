# Code Generation

> Last verified: 2026-08-16

Centrode uses three code generation systems. Understanding when and how to run each is critical.

---

## 1. FRB Codegen (Flutter Rust Bridge)

**Command**:
```bash
flutter_rust_bridge_codegen generate
```

**Config**: `flutter_rust_bridge.yaml`

**What it does**:
- Reads Rust API surface (`rust/src/bridge/api.rs`)
- Generates Dart bindings (`lib/src/rust/`)
- Generates Rust-side FRB glue (`rust/src/frb_generated.rs`)

**When to run**:
- After modifying any Rust type exposed via FFI
- After adding/removing `AppHandle` methods
- After changing Rust struct fields serialized across FFI

---

## 2. Dart build_runner

**Command**:
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

**What it does**:
- Runs `freezed` — generates immutable class implementations (`*.freezed.dart`)
- Runs `json_serializable` — generates JSON serialization (`*.g.dart`)
- Runs `centrode_codegen` — generates UiNode wrappers (`graph_node.ui.dart`)

**When to run**:
- After adding/modifying `@freezed` classes
- After adding/modifying `@JsonSerializable` classes
- After changing `UiNode` sealed class (triggers centrode_codegen)

---

## 3. Schema Generator (Rust)

**Command**:
```bash
cd rust && cargo test
```

Or dedicated schema gen command if available.

**What it does**:
- Reads Rust domain structs
- Generates `rust/src/persistence/schema.surql` (SurrealDB schema)

**When to run**:
- After adding/removing fields on domain structs
- After adding new node/relation types
- Never edit `schema.surql` directly

---

## Regeneration Order

After model changes, run generators in this order:

1. **Rust domain** → `cd rust && cargo test` (verifies + generates schema)
2. **FRB bindings** → `flutter_rust_bridge_codegen generate`
3. **Dart codegen** → `flutter pub run build_runner build --delete-conflicting-outputs`
4. **Verify** → `flutter analyze` should pass

---

## Autogenerated File Patterns

| Pattern | Generator | Edit source? |
|---------|-----------|--------------|
| `*.freezed.dart` | freezed | Yes — edit `@freezed` class |
| `*.g.dart` | json_serializable | Yes — edit `@JsonSerializable` class |
| `graph_node.ui.dart` | centrode_codegen | Yes — edit `UiNode` sealed class |
| `rust/src/frb_generated.rs` | FRB | No — generated from `bridge/api.rs` |
| `lib/src/rust/**/*.dart` | FRB | No — generated from Rust types |
| `rust/src/persistence/schema.surql` | schema_gen | No — generated from Rust structs |

## Troubleshooting

### "Conflicting outputs" error
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### FRB codegen fails
- Ensure LLVM is installed and on PATH
- Check `flutter_rust_bridge.yaml` for correct input/output paths
- Try: `flutter_rust_bridge_codegen generate --delete-conflicting-outputs`

### Schema not updating
- Run `cargo test` in `rust/` directory
- Check that your struct derives the required traits
- Verify `schema_gen/` modules are included in `persistence.rs`
