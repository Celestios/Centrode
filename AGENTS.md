# Mycelium

Flutter + Rust bilingual app: canvas-based knowledge graph with SurrealDB backend via Flutter Rust Bridge (FRB v2).

## Build & Run

```bash
flutter pub get
flutter run -d windows          # or linux, macos
```

## Code Generation (required after model changes)

```bash
flutter pub run build_runner build --delete-conflicting-outputs  # Dart freezed/json_serializable/mycelium_codegen
```

FRB bindings auto-generate from `rust/src/bridge/api` → `lib/src/rust` (config: `flutter_rust_bridge.yaml`).

SurrealDB schema (`rust/src/persistence/schema.surql`) is autogenerated from domain structs — never edit directly.

## Tests

```bash
flutter test                     # Dart unit/widget tests
flutter test integration_test    # Integration tests
cd rust && cargo test            # Rust backend tests
```

## Architecture

- `lib/features/graph/` — infinite canvas, node editing, routing engine
- `lib/features/workspace/` — project management
- `lib/infrastructure/` — telemetry, device services
- `lib/shared/` — shared widgets, glass panel rendering
- `rust/src/bridge/` — FFI endpoints (API surface for Flutter)
- `rust/src/domain/` — node/relation structs, patches
- `rust/src/persistence/` — SurrealDB connection, queries, history
- `rust/src/format/` — `.celi` zip package format
- `packages/mycelium_codegen/` — custom Dart codegen for UiNode wrappers

**Layer rule:** Lower tiers (domain, persistence) must never import from higher tiers (presentation, UI).

## Autogenerated Files — Do Not Edit

- `*.g.dart`, `*.freezed.dart`, `graph_node.ui.dart` — modify annotated source, re-run build_runner
- `rust/src/persistence/schema.surql` — modify domain structs, run schema generator
- `rust/src/frb_generated.rs` — generated by FRB, do not touch

## Git Conventions

- **Branch naming:** `<type>/<scope>-<kebab-desc>` — types: `feat|fix|refactor|perf|docs|chore|test`; scopes: `graph|node|relation|tags|ui|ffi|db|workflow|model`
- **Commits:** Conventional Commits format — `feat(ui): add zoom support` with required body (except `chore(release):`)
- **No direct commits to main/master** — use feature branches
- **File ops:** Use `git rm` / `git mv` (not filesystem delete/move) to preserve history

## Version Sync

Version is shared between `pubspec.yaml` and `rust/Cargo.toml`. Use `dart scripts/sync_version.dart` to keep them aligned.

## Graphify

Knowledge graph at `graphify-out/`. When user types `/graphify`, invoke the `skill` tool with `skill: "graphify"`. After code changes, run `graphify update .` to keep graph current.

## Style Rules

- No error handling, no fallbacks, use standard logging, no migrations
- Don't add comments unless asked
