# Skill: Physics & Layout Simulation

Use this skill when designing or implementing canvas layout algorithms, spring forces, coordinate maths, and viewport boundaries.

## Guidelines

- **Force-Directed Layouts**: Ensure link forces, node charge forces, and collision physics are computed efficiently to prevent lag.
- **Spring Physics**: Adopt clean spring parameter configurations (stiffness, damping, mass) for smooth UI movements.
- **Viewport Restrictions**: Design robust boundary restrictions to keep nodes from escaping visible canvas scopes.
