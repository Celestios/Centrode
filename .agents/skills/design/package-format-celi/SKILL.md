# Skill: Package & Package Format (.celi)

Use this skill when designing or implementing zip compression archives, file-system directories, and serialization models for project save files.

## Guidelines

- **Compression Layouts**: Maintain clean package structures in `.celi` zip archives (representing node, relation, tag metadata, and canvas configs).
- **Directory Hierarchies**: Follow standardized relative path locations for saved objects within the project folder format.
- **Serialization Formats**: Implement robust JSON or binary serialization traits for loading/saving data.
