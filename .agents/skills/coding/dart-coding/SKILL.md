# Skill: Dart Coding (Core Dart & Flutter Development Guide)

This skill must be activated and followed strictly whenever writing or modifying Dart/Flutter code in the `lib/` or `test/` directories.

## Architectural Mandates & Decisions

### 1. 3-Tier Layer Boundaries
- **Tier 1 (Presentation & Interface)**: `lib/features/graph/ui/` — Canvas painting, widgets, overlays. LOWEST tier.
- **Tier 2 (Interaction & Controllers)**: `lib/features/graph/presentation/`, `lib/features/graph/engine/` — State machines, gesture state, command processing.
- **Tier 3 (Core Domain & Storage)**: `lib/features/graph/store/`, `lib/features/graph/models/` — FFI sync, SurrealDB domain store. HIGHEST tier.
- **Rule**: Higher tiers must NEVER import or depend on lower tiers. UI widgets (Tier 1) must never make direct database queries/writes; they emit events/commands to Tier 2.

### 2. Canvas Painting & Rendering Engine
- **Composite Picture Caching**: Use a single `CustomPainter` with dual `ui.Picture` caching (`_nodeCache` per node, `_cachedPicture` per layer). Translate cached GPU pictures during panning/dragging; isolate active text editing outside `RepaintBoundary`.
- **Spatial Indexing & Hit Testing**: Use `SpatialHashGrid` (fixed 1000px chunks, $3\times3$ neighborhood queries) for $O(1)$ spatial queries. Perform priority-ordered raycasting via `HitTestResolver` (handles $\rightarrow$ ports $\rightarrow$ nodes $\rightarrow$ polyline edges) rather than widget tree hit testing.
- **Hysteresis Overscan Buffering**: Inflate visible screen bounds by 25% (`overscanRatio = 0.25`). Only trigger visible node set updates when the viewport breaches the overscan buffer.
- **Affine Drag Transformations**: Apply local linear point transforms during active node drags; defer heavy `PathMetric` dashed/dotted stroke pattern calculations to paint time.

### 3. Glass UI & Context Layouts
- **Backdrop Capture Pipeline**: Downsample glass shader backdrop captures to 25% scale (`scale = 0.25`). Limit active glass panels per group to 4 rect uniforms. Use progressive warmup step timers (`[100, 400, 1000, 2500]` ms) to capture background updates.
- **Context Toolbar Anchoring**: Anchor floating toolbars in screen space with dynamic left-to-right side-flipping (`leftThreshold` check) and viewport bounds clamping.
- **Color Contrast Adaptation**: Use complementary ARGB LUT swatches for preset colors with dynamic WCAG relative luminance fallback ($L < 0.5$).

### 4. Micro-Reactivity & Async Execution
- **State & Debouncing**: Use scoped `ValueNotifier`/`ChangeNotifier` micro-reactivity. Debounce high-frequency gestures at 300ms before sending commands to Rust.
- **Physics Tick Interpolation**: Receive 16ms Rust physics ticks and interpolate positions across 4ms sub-steps using LERP with adaptive degradation when tick queues back up.

### 5. Autogenerated Files & Rules
- Do NOT edit generated files (`*.g.dart`, `*.freezed.dart`, `graph_node.ui.dart`). Re-run `flutter pub run build_runner build --delete-conflicting-outputs` after annotations update.
- Zero fallbacks/defensive try-catch. Let exceptions crash visibly and log via standard logger. No database migrations. No unrequested comments.

## Verification Checklist

1. Run `flutter test` to verify widgets and models.
2. Run `flutter analyze` to ensure zero static analyzer issues.
