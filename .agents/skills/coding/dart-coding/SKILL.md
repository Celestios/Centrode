# Skill: Dart Coding (Core Dart & Flutter Development Guide)

This skill must be activated and followed strictly whenever writing or modifying Dart/Flutter code in the `lib/` or `test/` directories.

## Core Mandates

### 1. 3-Tier Layer Boundaries
You must strictly respect the application layers:
- **Tier 1 (Canvas UI)**: `lib/features/graph/ui/` — Renders the infinite canvas, nodes, relations, and toolbars.
- **Tier 2 (Presentation & Interaction)**: `lib/features/graph/presentation/` — State-coordination, gesture management, command patterns.
- **Tier 3 (Domain / Store)**: `lib/features/graph/store/` or `models/` — FFI bridge interaction, persistence.
- **Rule**: Lower tiers (Tier 3) must NEVER import or reference higher tiers (Tier 1/2). Tier 2 must never import Tier 1. UI widgets (Tier 1) must never make direct database queries or writes; they must emit events or commands to Tier 2.

### 2. Autogenerated Files
- Do NOT edit generated files (`*.g.dart`, `*.freezed.dart`, `graph_node.ui.dart`).
- When modifying classes annotated with `@freezed`, `@JsonSerializable`, or custom annotations, run:
  ```bash
  flutter pub run build_runner build --delete-conflicting-outputs
  ```

### 3. Spatial UI & Aesthetics
Ensure the user interface matches premium quality standards:
- **Aesthetics**: Adhere to Glassmorphism 2.0 specs from [smart-glass.md](file:///d:/Projects/Open/flutter/code/mycelium/.agents/plugins/spatial-ui/rules/smart-glass.md). Use HSL color maps, layered opacities, and fine borders.
- **Motion & Performance**: Adhere to spring physics and repaint limits from [motion-performance.md](file:///d:/Projects/Open/flutter/code/mycelium/.agents/plugins/spatial-ui/rules/motion-performance.md). Place `RepaintBoundary` wrappers on fast-moving canvas elements, and limit the usage of complex widgets like `BackdropFilter` inside scrollable areas.

### 4. Style Rules & Logging
- Do NOT add error-handling fallback overrides. Let exceptions propagate and log them using the standard telemetry/logger.
- Do NOT write migrations.
- No comments unless requested.

## Verification Checklist

1. Run `flutter test` to verify widgets and models.
2. Run `flutter analyze` to ensure the static analyzer passes with zero issues.
