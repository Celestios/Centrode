# Rule: Smart Glass & Semantic Design System

You MUST adhere to these design system rules when rendering and styling UI components:

## 1. Visual Paradigm: "Smart Glass" (Glassmorphism 2.0)
- Apply glassmorphism components to the infinite canvas spatial UI.
- Glass panels must utilize precise blend modes, border highlights, backdrops, and blur parameters:
  * Use a subtle translucent background with micro-borders for structural delineation.
  * Collapsible sidebars, mini-maps, and floating overlays must follow the glass blueprint.

## 2. Semantic Aesthetics & Layout Strategy
- Aesthetics MUST actively serve data comprehension. Purely decorative elements are secondary.
- Visual traits (color, shadow, depth, opacity, motion) must map semantically to underlying graph dimensions:
  * **Node Weight / Significance**: Map to opacity levels, depth elevation, or blur parameters.
  * **Relation Type**: Map to distinct stroke designs, colors, or opacity.
  * **Tags & Categories**: Map to semantic color indicators.
- **Graph Interaction & Layout**:
  * Differentiate visually between standard nodes, relation edges, and internodes.
  * Maintain clean layout mechanics that balance organic exploration with logical structure, respecting relation obstacle avoidance.
